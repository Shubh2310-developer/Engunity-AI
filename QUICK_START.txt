📦 INSTALLATION
────────────────────────────────────────────────────────────────

1. Install Backend Dependencies:
   cd code-executor && npm install

2. Install Frontend Dependencies:
   cd ../frontend && npm install

3. Install Socket.IO Client (if not done):
   npm install socket.io-client


🚀 START SERVICES
────────────────────────────────────────────────────────────────

Option 1: Manual Start (Recommended for Development)
──────────────────────────────────────────────────────

Terminal 1 - MongoDB:
   docker run -d --name engunity-mongo -p 27017:27017 mongo:7.0

Terminal 2 - Backend:
   cd code-executor
   npm run dev

Terminal 3 - Frontend:
   cd frontend
   npm run dev


Option 2: Docker Compose (Recommended for Testing)
───────────────────────────────────────────────────

   docker-compose up -d


🌐 ACCESS APPLICATIONS
────────────────────────────────────────────────────────────────

Frontend:       http://localhost:3000
Code Editor:    http://localhost:3000/dashboard/editor
Backend API:    http://localhost:4000/api
Health Check:   http://localhost:4000/health
MongoDB:        mongodb://localhost:27017


🧪 TEST CODE EXECUTION
────────────────────────────────────────────────────────────────

Python Example:
───────────────

  -H "Content-Type: application/json" \
  -d '{"code": "print(\"Hello World!\")", "language": "python"}'

───────────────────

🛑 STOP SERVICES
────────────────────────────────────────────────────────────────

Stop Backend:     Ctrl+C in Terminal 2
Stop Frontend:    Ctrl+C in Terminal 3
Stop MongoDB:     docker stop engunity-mongo
Stop All:         docker-compose down

🆘 TROUBLESHOOTING
────────────────────────────────────────────────────────────────

Port Already in Use:
   lsof -i :3000  # or :4000
   kill -9 <PID>

Docker Not Running:
   sudo systemctl start docker

MongoDB Connection Failed:
   docker restart engunity-mongo

WebSocket Connection Failed:
   Check backend is running on port 4000
   Verify .env.local has correct WS_URL
